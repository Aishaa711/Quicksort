    From the lecture

    • The pivot is the last element of the current sub-array. After partition, it sits in its final sorted place, with smaller or equal values on its left and bigger values on its right.
    • Time: average case O(n log n). Worst case O(n²), for example an already sorted array with the last element as pivot. Try the worst case button and watch the comparison count.
    • Quick Sort is not stable: equal values can change their relative order.
    • It sorts in place. Besides the array it needs only one temporary variable for swapping, plus the recursion call stack.
